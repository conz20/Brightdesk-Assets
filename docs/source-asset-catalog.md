# Source-mirrored Brightdesk artwork

**Purpose:** This catalog records exact copies of artwork already maintained in the ten Brightdesk product repositories. The files are mirrored here so the shared asset library can offer a single, browsable home.

## Important distinctions

- Product icons and social banners are the source-owned images used by or published with the corresponding product repositories.
- Workspace previews are source-owned design previews and product concepts. They are **not** screenshots of running applications and do not prove that depicted features work.
- None of these copied files is automatically approved for redistribution in customer installers. The approved distribution registry `assets/manifest.json` remains the authority and is unchanged.
- No file has been redrawn, restyled, recoloured or otherwise altered during this mirror operation. The source Git blob SHA is recorded for exact comparison.
- Sources were read from each listed repository's `main` branch on 2026-11-14. The source path and Git blob SHA make the original content traceable.

## Updating the mirrors

When a product repository changes one of these source assets, update the matching file here from the new source version and update its source Git blob SHA in this catalog. Do not alter the mirrored artwork locally in a way that makes it diverge from the product source. If a central-only adaptation is needed, store it separately and label it as an adaptation.
