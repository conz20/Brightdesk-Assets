# Brightdesk concept artwork

This directory contains ten original, editable SVG concept illustrations, one for each approved customer product.

**Classification: concept artwork.** These are not screenshots of running products and do not prove that any depicted interface or workflow exists. Do not use them as verified screenshots, release evidence or claims of implemented functionality. They are not registered in `assets/manifest.json`, which remains the approval registry for distributable customer assets.

## Collection

- [Pages](product-illustrations/pages.svg) — Document design
- [Sheets](product-illustrations/sheets.svg) — Spreadsheets and analysis
- [Decks](product-illustrations/decks.svg) — Presentation storytelling
- [Notes](product-illustrations/notes.svg) — Quick capture and ideas
- [Database](product-illustrations/database.svg) — Structured records
- [Forms](product-illustrations/forms.svg) — Form building and responses
- [Lists](product-illustrations/lists.svg) — Trackable lists
- [Planner](product-illustrations/planner.svg) — Plans and schedules
- [To Do](product-illustrations/todo.svg) — Personal tasks
- [Workspace](product-illustrations/workspace.svg) — Unified work hub

The artwork uses original vector geometry and a consistent visual language. It contains no Microsoft or Adobe logos, copied product screenshots, external image URLs or third-party fonts.
