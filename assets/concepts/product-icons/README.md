# Brightdesk product icon concepts

This folder contains ten original, editable SVG icon concepts—one for each approved Brightdesk customer product.

**Classification: concept artwork.** These are exploration assets, not approved final product icons, not screenshots, and not evidence of implemented features. Do not add them to customer builds or `assets/manifest.json` until the icon design is formally approved and the rights/provenance record, redistribution permission, bundling permission and SHA-256 record are complete.

## Design and technical notes

- Consistent 256 × 256 viewBox, rounded square frame and restrained product accent
- Original vector geometry; no copied Microsoft or Adobe logos, product icons or screenshots
- Accessible SVG title and description in every file
- No embedded raster images, scripts, external references or third-party fonts
- Files remain separate so each concept can be reviewed and revised independently

The concepts are deliberately distinct from the larger product-interface illustrations in [product-illustrations](../product-illustrations/).
